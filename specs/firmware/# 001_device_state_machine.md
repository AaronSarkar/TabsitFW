# Device State Machine

BOOT
↓
INITIALIZING
↓
READY

READY:

* show tasks
* accept input

READY
→ DISCONNECTED

DISCONNECTED
→ RECONNECTING

RECONNECTING
→ READY

READY
→ SLEEP

SLEEP
→ WAKE

ERROR
→ RECOVERY
